| Name | Number | Description |
| ---- | ------ | ----------- |
| BUILD_STATUS_PHASE_UNSPECIFIED | 0 |  |
| BUILD_STATUS_PHASE_PENDING | 1 | Waiting for a trigger event or dependency to be ready. |
| BUILD_STATUS_PHASE_RUNNING | 2 | A BuildRun is currently executing. |
| BUILD_STATUS_PHASE_SUCCEEDED | 3 | The most recent BuildRun completed successfully. Image has been pushed to the registry. |
| BUILD_STATUS_PHASE_FAILED | 4 | The most recent BuildRun failed. Check execution_ref for BuildRun details. |

<a name="blanketops-common-v1-DomainTLSStrategy"></a>

### DomainTLSStrategy
DomainTLSStrategy

Controls which cert provisioning path the Domain controller takes.

  platform — The platform wildcard cert (*.dev.host) already covers this
             host via a DNS01 ClusterIssuer. Controller emits DomainClaim &#43;
             DomainMapping only — no Certificate work is needed.

  custom   — Client-owned zone (e.g. client-a.co.za). Controller emits
             Issuer &#43; DomainClaim &#43; DomainMapping &#43; Certificate. HTTP01
             ACME challenge via the nginx solver in the tenant namespace.


| Field | Type | Label | Description |
| ----- | ---- | ----- | ----------- |
| strategy | [DomainTLSStrategy.DomainTLSStrategy](#blanketops-common-v1-DomainTLSStrategy-DomainTLSStrategy) |  | strategy is the selected TLS provisioning path. |





 


<a name="blanketops-common-v1-DomainPhase-DomainPhase"></a>

### DomainPhase.DomainPhase


| Name | Number | Description |
| ---- | ------ | ----------- |
| DOMAIN_PHASE_UNSPECIFIED | 0 | Unset — should never appear in a reconciled CR. |
| DOMAIN_PHASE_PENDING | 1 | Controller has accepted the CR but cert/mapping work has not started. |
| DOMAIN_PHASE_PROVISIONING | 2 | Cert or DomainMapping is being provisioned (Issuer, Certificate, or DomainClaim are in-progress). |
| DOMAIN_PHASE_READY | 3 | Cert is issued, DomainMapping is active, and mTLS (when enforced) is wired. The host is reachable. |
| DOMAIN_PHASE_FAILED | 4 | Terminal failure — cert issuance failed, DomainMapping rejected, or an ACME HTTP01 challenge could not be satisfied. |



<a name="blanketops-common-v1-DomainTLSStatus-DomainTLSStatus"></a>

### DomainTLSStatus.DomainTLSStatus


| Name | Number | Description |
| ---- | ------ | ----------- |
| DOMAIN_TLS_STATUS_UNSPECIFIED | 0 |  |
| DOMAIN_TLS_STATUS_DISABLED | 1 | TLS is not configured for this domain. |
| DOMAIN_TLS_STATUS_PROVISIONING | 2 | Cert issuance or DomainMapping creation is in progress. |
| DOMAIN_TLS_STATUS_ACTIVE | 3 | Cert is valid and DomainMapping is serving TLS traffic. |
| DOMAIN_TLS_STATUS_FAILED | 4 | Cert issuance failed or the cert has expired. |



<a name="blanketops-common-v1-DomainTLSStrategy-DomainTLSStrategy"></a>

### DomainTLSStrategy.DomainTLSStrategy


| Name | Number | Description |
| ---- | ------ | ----------- |
| DOMAIN_TLS_STRATEGY_UNSPECIFIED | 0 |  |
| DOMAIN_TLS_STRATEGY_PLATFORM | 1 | Platform wildcard cert path — DNS01 ClusterIssuer, already issued. Controller emits DomainClaim &#43; DomainMapping only. |
| DOMAIN_TLS_STRATEGY_CUSTOM | 2 | Client-owned zone — HTTP01 cert path. Controller emits Issuer &#43; DomainClaim &#43; DomainMapping &#43; Certificate. |
